# 공식 2.7.7 선택 반영 기록

2026-09-22, 공식 v2.7.7(ad5b29a)까지의 변경 중 사용자 선택 1·5·8·9·10만 반영.
사용자 지정에 따라 VERSION의 dashboard·DBMS 표시를 2.7.7로 설정한다. 이는 아래 선택 반영 범위를 뜻하며, 제외 항목까지 반영했다는 의미는 아니다.
Compose의 로컬 빌드, MariaDB, Redis, 볼륨 구성은 유지한다.

## 반영 사항

- MCP: 검색 정렬, 무작위 시리즈 선택, 요청 개수 초과 반환 수정.
- 오디오북/영상 대체 표지: 중복 DB 조회 제거, ETag 및 조건부 304 응답. 권한 확인을 유지하기 위해 공식 public 캐시 대신 private,no-cache 재검증 사용. 304일 때 SVG를 재생성하지 않는다.
- 목록: 그룹핑 후 카드 수 대신 원본 행 수로 has_more 판정. 전체 목록 캐시와 로컬 초성 경량 캐시도 선택적 (목록,has_more) 반환을 지원한다. 기존 호출의 목록 반환 계약은 유지한다.
- 정적 자산: JSZip, PDF.js/worker/CMaps, Marked, 로그인 폰트를 로컬 제공한다.
- 샘플 플러그인: 네이버웹툰 시리즈 표지 추가 및 실제 설치. bo_relayss 샘플의 외부 아이콘 CDN 제거. bo_relayss는 기존 설치가 없어 새로 설치하지 않았다.

## 이후 업데이트에서도 제외할 항목

사용자 지시: 아래 2·3·4·6·7번은 이후 공식 업데이트에서도 반영하지 않는다. 누적 업데이트나 병합 시 이 변경이 다시 유입되지 않도록 확인한다. 사용자가 명시적으로 변경을 요청한 경우에만 재검토한다.

- 3번: 공식 제목·주제·회차 검색 오버레이 및 관련 검색 동작 변경. 현재 커스텀 검색 미리보기와 전체 검색을 유지한다.
- 4번: 공식 관리자 카드 정보 버튼 및 잠금 배지 위치 변경.
- 6번: 메인 카드 표지를 늘려 채우기에서 크롭 표시로 바꾸는 변경.

- 2번: 백그라운드 표지 축소 작업이 fake_screen.png(보스키 위장 화면)까지 축소하지 않게 하고, 배너에는 큰 배너 전용 크기 한도를 적용한다. 이미 작아진 이미지의 원본을 복구하는 기능은 아니다.
- 7번: 여러 개별 권의 표지 표시 위치를 왼쪽/중앙/오른쪽으로 일괄 지정하는 기능. 책 순서 변경이나 원본 이미지 편집이 아니다. 기존 상세화면의 단일 권 정렬은 유지한다.

## 예외 3건 및 수정

1. 초성 캐시 적중 후 API 오류: 로컬 전용 경량 캐시가 목록만 반환하여 새 API의 두 값 unpack과 불일치. 동일한 반환 계약으로 통일하고 기존 목록 전용 호출도 검증했다.
2. MCP 검색 개수에 음수/0/비정수 입력: 음수 슬라이스로 요청과 다른 결과를 반환할 수 있었다. 1~1000의 정수만 허용하고 조회 전에 검증한다.
3. 네이버웹툰 이미지 URL이 HTTP 200 오류 HTML을 반환: 공식 샘플이 인코딩 실패 데이터를 .webp로 저장하고 시리즈 전체 표지로 지정했다. 이미지 검증과 임시 파일을 통한 교체를 적용하고 실패 시 기존 표지 및 DB를 유지한다.

## 검증

- 운영 DB/네트워크와 분리한 테스트 컨테이너: Python 31 passed, 8 subtests passed.
- 프런트엔드: Node 39 tests passed (뷰어/검색/모드/컨트롤).
- 검색 저장소의 기존 테스트 데이터에 라이브러리 권한이 누락되어 6건이 실패했으며, 로컬 정책에 맞는 명시적 권한을 테스트 DB에 부여한 후 통과. 운영 권한 로직은 완화하지 않았다.
- 실제 Chromium: CDN 차단 상태로 로컬 자산 6종 HTTP 200, JSZip 압축/해제, PDF worker 1페이지 렌더링, EPUB 표시, JS 오류 0건.
- 실제 API: 일반/오디오북/영상 목록, 초성 이동 후 목록 성공. 현재 오디오북/영상은 비어 있으므로 다량 그룹핑 사례는 모의 데이터로 검증했다.
- 실제 MCP 함수: 최근 추가순 검색 2건, 무작위 선택 성공.
- 네이버웹툰 설치/핫 리로드 성공, 실제 검색 8건. 실제 소장 도서의 표지를 변경하는 적용 작업은 수행하지 않았다.
- git diff --check 및 Compose 설정 검사 통과. 앱 이미지 재빌드/반영 및 실행 상태 확인.

검증 범위에서 실패는 해소했다. 모든 기기, 원격 파일, 실제 대규모 오디오북/영상 데이터에 대한 무결함 보장은 아니다.
