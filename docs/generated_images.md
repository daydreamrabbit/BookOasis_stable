# 생성 표지·배너 파일 관리

새로 생성하는 도서 이미지는 `카테고리ID/작품명_권수__bo_종류_구분값.webp`,
배너는 `카테고리ID/작품명_배너__bo_banner_구분값_내용버전.webp` 형태로 저장합니다.
권수는 원본 파일명에서 추출하며, 식별되지 않으면 파일명을 사용합니다.
작품명 부분은 최대 10자로 줄입니다. 권수·배너 표시와 충돌 방지 구분값은 자르지 않습니다.
구분값은 경로에서 계산하므로 같은 이름의 다른 파일이 서로 덮어쓰지 않습니다.
외부 표지와 파일에서 추출한 표지는 서로 구분합니다. 기존 DB 이미지 경로는 일괄 변경하지 않습니다.

카테고리 삭제 성공 후, 모든 미디어 DB의 이미지 경로와 설정 내 이미지 참조를 확인해
사용하지 않는 카테고리 이미지 파일을 정리합니다. 다른 DB에 같은 카테고리 ID가 있으면
임의 업로드 파일은 보존합니다. 참조 확인 실패 시 정리를 보류합니다.

서버는 매시간 숫자 카테고리 폴더의 생성 이미지 중 미참조 파일을 점검합니다.
파일 생성 후 24시간이 지나야 정리하여 DB 저장 전의 작업 중 이미지를 보호합니다.
직접 업로드한 알 수 없는 이름, 심볼릭 링크, 원본 도서, plugin_logo는 이 자동 정리에서 제외합니다.
사용 중인 옛 해시 파일명도 그대로 보존합니다.

이 자동 정리는 휴지통 이동이 아닌 파일 삭제입니다. 데이터 백업에는 DB뿐 아니라 covers도 포함하세요.
