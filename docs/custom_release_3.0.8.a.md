# 커스텀 릴리스 3.0.8.a

공식 3.0.8까지의 필요한 개선을 선택 반영한 커스텀 릴리스다. 공식 전체 교체 버전은 아니다.

반영: PDF.js 6.4.299, EPUB 이미지 응답 제한과 SVG sandbox, 책/표지 디코더 제한, 보안 의존성과 APScheduler 갱신, 리다이렉트 다운로드 파일명 수정. 기존 PDF/TTS/표지/AVIF/GIF/읽기 진행/증분 스캔 처리를 유지한다.

미반영: 다운로드 하위 폴더 옵션, 다국어 확장과 언어 쿠키/검색 안내, HTTP 화면 꺼짐 안내, TTS 로그 영어화. 현재 운영에 없는 GDrive 메타데이터 미러 기능과 네이티브 manage.sh 옵션도 도입하지 않았다.

DBMS 리비전은 custom-20261025.1을 유지한다. 이번 릴리스에서 DB 구조나 데이터를 변경하지 않는다.

검증: 실제 PDF 엔진의 데스크톱/모바일 브라우저 렌더링과 커스텀 텍스트 터치/이어읽기/두 쪽 보기/스크롤/닫기/빠른 책 전환, 격리된 실제 EPUB/다운로드/TTS 라우트와 권한 검사, AVIF/GIF와 표지 선택, 별도 SQLite/MariaDB의 스캔/요약 회귀, 앱 기동과 정상 종료, 배포 전후 스키마·메타데이터·표지·읽기 진행 해시 보존을 확인했다.

tests/test_security_308.py에 보안 및 커스텀 회귀 검사를 포함한다. 테스트는 별도의 DB/저장소를 사용하는 격리 환경에서 실행한다. 실제 모바일 음성 재생과 모든 PDF의 특수 폰트/JPX/JBIG2를 전수 검사한 것은 아니다.

## 오류 문구 보완

한국어·영어 사전에 사용자 없음, 마지막 관리자 삭제 불가, 현재 비밀번호 필요, 현재 비밀번호 불일치, 스캔 카테고리 없음 문구를 추가했다. 오류 응답의 HTTP 상태와 권한·계정·스캔 처리 코드는 변경하지 않았다. 두 언어의 실제 번역 함수와 오류 응답 표현식을 격리 검사했다. 앱 버전과 DBMS 리비전은 유지한다.
