# 발행 상태와 보유 누락의 분리

플러그인이 제공한 publication_status(연재/휴재/완결)는 그대로 저장한다. 보유 누락은 오아시스가 현재 조회 권한과 카테고리·폴더 범위의 권번호를 비교해 계산한다. 스캔이나 원본 파일 수정, DB 마이그레이션은 필요하지 않다.

확인된 최고 정수 권번호 이전의 빈 번호는 발행 상태와 무관하게 누락으로 검색한다. 예를 들어 31권 하나만 있으면 1~30권 누락이다. 상세에는 누락 범위와 원래 연재 배지를 함께 표시한다. 연재·휴재의 총 권수만으로 앞으로 나올 권까지 누락으로 판단하지 않는다. 완결/상태 미지정에서 기존 총 권수 기반 판정은 유지한다.

중복 권번호는 한 번만 세고, 0권·소수 권번호·외전은 본편 번호를 채우지 않는다. 권번호가 있으면 회차 번호를 섞어 세지 않는다. 범위를 확정하기 어려운 합본·전권·상하권 등은 자동 누락 단정에서 제외한다. 제목에서 숫자를 새로 추정하거나 외부 서지 DB의 상태를 저장하지 않는다.

검색 목록·총계·인덱스·필터 선택지에 동일한 SQL 판정을 적용한다. 상세도 같은 기준으로 계산하되 기존 메타데이터·권한·독서 기록은 유지한다.

검증: SQLite/MariaDB에서 31권 단독·전체 보유·연재 미래 총수·완결 꼬리 누락·중복/소수/외전/합본·회차/권수 혼합·폴더 경계 검사, 검색 권한/페이지/인덱스/총계/선택지 및 실제 상세 응답 회귀, 모바일/데스크톱 배지와 안전한 텍스트 출력을 확인했다.

## 단권·특수 항목 정렬용 값

기존 document_volume_index의 100000 이상은 단권/특수 항목 정렬용 예약값이다. 이 값은 실제 권번호로 세지 않는다. 메타데이터나 정렬값은 수정하지 않는다. 회차(document_number)의 유효 범위는 별도로 유지한다. 총 권수 1인 단권의 예약값을 100000권으로 읽어 누락이라고 표시하던 오탐을 수정했다. 이는 단순히 파일이 한 개라는 이유로 제외하는 규칙이 아니며, 31권 파일 하나만 보유한 작품은 여전히 1~30권 누락이다.
