# 스캔 실패 원인과 작업 중단 리포트

알림과 최근 스캔 이력에 저장된 실패 원인을 표시한다. 긴 Traceback은 요약에서 제외하고 인증정보를 가린다. 오류 문자열은 HTML 대신 텍스트로 표시한다.

에러 리포트 뷰어는 기존 파일별 오류와 함께 최근 작업 중단 이력을 표시한다. 카테고리/미디어 종류별로 최대 50개를 기존 scan_history에서 읽는다. 작업 중단 내역을 파일 오류나 파일 손상으로 단정하지 않는다. 데이터베이스 구조나 과거 이력을 변경하지 않고, 별도 리포트 파일도 생성하지 않는다. 조회는 기존 관리자 권한을 유지한다.

폴더 감시의 변경 목록 재확인, 파일 안정화 보호, 마운트 검증, 삭제 보호 및 재시도 처리는 변경하지 않는다. 취소·실패 상태도 그대로 유지한다.

검증: SQLite/MariaDB 격리 조회·상태/카테고리 경계·관리자 권한·기존 리포트 공존·문구 정리, 모바일/데스크톱 브라우저의 세 화면과 안전한 텍스트 출력을 확인했다. 실제 파일 변경이나 재스캔을 실행해서 보호 로직을 우회하지 않았다.
